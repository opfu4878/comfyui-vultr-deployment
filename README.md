## 云端跑 ComfyUI，机器配置看什么？

先说结论：显存决定体验，其他都是次要的。

ComfyUI 对低配机器相当宽容。按官方仓库的说明，它有智能显存管理，1GB 显存的卡靠自动 offload 也能跑大模型；显存低于 3GB 会自动进入 lowvram 模式；彻底没显卡，加 `--cpu` 参数也能出图。注意措辞——是“能跑”。1GB 显存跑大模型、纯 CPU 出图，都意味着一次生成要等上几分钟，学习节点连线够用，干正经活不行。

反过来，真正舒服的档位是 16GB 显存起步：SDXL 级别的图随便跑，Flux 这类大模型配合 offload 也能应付。再往上，视频生成（Wan、LTX-Video、HunyuanVideo 这些模型族）和大批量生产才需要更大的显存。

除了显卡，还有两件事值得留意：Linux 是 ComfyUI 官方完整支持的部署环境，手动安装没有任何障碍；流量要够用，因为模型文件动辄几个 GB，下载模型和传回成品都走流量。

## 部署步骤：十来分钟把 ComfyUI 跑起来

整体流程是：开一台 Ubuntu 服务器 → SSH 连上去 → 装 Python 环境 → 拉取 ComfyUI 代码 → 放模型 → 启动。全程不需要写代码，命令照抄即可。

1. **开机器**：选 Cloud GPU 档位，系统镜像选 Ubuntu 24.04 LTS（自带 Python 3.12，版本够新）。
2. **SSH 连接并开隧道**：本地终端执行：

bash
ssh -L 8188:localhost:8188 root@你的服务器IP


这样 ComfyUI 的界面只监听服务器本机，不用把端口暴露到公网，安全性最好。

3. **装环境**：

bash
apt update && apt install -y python3-venv git
python3 -m venv venv && source venv/bin/activate


4. **拉代码并安装依赖**：

bash
git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI
pip install torch torchvision torchaudio
pip install -r requirements.txt


Linux 上直接 pip 安装的 torch 默认就是 CUDA 版；想锁定特定 CUDA 版本，官方 README 里有现成命令，NVIDIA 和 AMD（ROCm）各有一条，照抄即可。

5. **放模型**：checkpoint 类模型放进 `models/checkpoints`，VAE 放进 `models/vae`。ComfyUI 核心本身完全离线运行，不会自己下载任何东西，模型都需要你手动放进去。
6. **启动**：

bash
python main.py


默认监听本机 8188 端口，浏览器打开 `http://localhost:8188` 就能看到节点界面。第一次没模型的话，先从官方模板库里挑一个工作流练手。

7. **打快照**：环境调好后在控制台创建快照。以后想换更高档的机型，直接从快照恢复环境，不用重装一遍。

## 真实成本：按小时跑和包月常开差多少

按小时计费的意义，要算过才知道有多大。

以 A16 档约 $0.36/小时计算：每天开机 2 小时、每周 5 天，一个月约 40 小时，花费 $14 左右；同一台机器 7×24 常开，则封顶在 $269/月。差出一个数量级还多。

所以 ComfyUI 云部署最省钱的使用姿势是：临时开机 → 跑图 → 销毁实例 → 快照留底。销毁之后计算费用立即停止，只剩快照的存储费按容量慢慢算，比整月开机便宜得多。安装环境本身只要十来分钟，这套流程完全可循环。

有一点要提前想清楚：模型文件（动辄 5–10GB）如果不放在快照或对象存储里，每次开新机都要重新下载。把模型放对象存储，或用 `extra_model_paths.yaml` 固定路径，能把这部分时间省掉。

## 常见问题

### 用 $5 的普通 VPS 部署 ComfyUI 现实吗？

装得起来，跑不痛快。CPU 模式下 SD1.5 出一张图按分钟计，配合低显存模式倒不至于跑不起来。当学习机可以，当生产工具不行。

### 不想碰命令行，有什么办法？

两条路。一是 ComfyUI 官方的付费云版 Comfy Cloud，完全不用管服务器；二是照着上面的步骤抄，实际要敲的命令不超过十行，而且只需要做一次，之后都是快照恢复。

### 8188 端口要不要对外开放？

不建议。用 SSH 隧道方案时，界面只在服务器本机监听，公网扫不到。真有多人访问的需求，再考虑反代加认证，别把裸端口挂到公网。

### 换机型或重装系统，模型和工作流会丢吗？

实例销毁后磁盘数据会清空，快照和对象存储里的东西会留下。所以习惯应该是：环境靠快照，模型靠对象存储或固定路径配置，工作流本身导出成 JSON 存一份。ComfyUI 原生支持从生成的图片里反推完整工作流和种子，等于还有一道双保险。
